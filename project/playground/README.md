# Playground

Einziger Arbeitsbereich der Übungen. Der Trainer kopiert den Starter eines Labs hierher, entwickelt live und zeigt danach das Beispiel unter `examples/`. Teilnehmende arbeiten im eigenen Playground und vergleichen mit `examples/`.

```bash
cp starters/m01-l02-first-server.py playground/server.py
python playground/server.py                       # stdio-Server, wartet auf einen Client
npx @modelcontextprotocol/inspector python playground/server.py
```

Die Dateien in diesem Ordner (außer dieser) gehören nicht zum Kursstand und werden nicht versioniert.
